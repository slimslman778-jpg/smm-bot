# Telegram Video Compressor — Link Edition

بوت Telegram تجريبي حقيقي:
رابط فيديو عام → تنزيل → ضغط FFmpeg → إرسال الفيديو المضغوط.

## التشغيل
ضع:
BOT_TOKEN=توكن_البوت

ثم:
npm install
npm start

## Render
ارفع المشروع إلى GitHub، ثم أنشئ Web Service باستخدام Docker.
أضف BOT_TOKEN في Environment Variables.

## ملاحظات
- يدعم في هذه النسخة الروابط المباشرة/العامة التي يستطيع الخادم الوصول إليها.
- لا يتجاوز حماية DRM أو يتخطى تسجيل الدخول أو صلاحيات المواقع.
- بعض منصات الفيديو لا تعطي ملف MP4 مباشرًا للرابط؛ دعم المنصات الخاصة يمكن إضافته لاحقًا.
- الحد الافتراضي للتنزيل 500MB للاختبار، ويمكن تغييره عبر MAX_DOWNLOAD_MB.
- الضغط حقيقي بواسطة FFmpeg.
